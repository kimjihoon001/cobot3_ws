# 작업 인수인계 — 스마트팜 통합 후속 작업 (2026-07-25)

이 문서는 다음 작업자가 이미 끝난 원인 조사를 반복하지 않고, 현재 미완료 작업부터
이어가기 위한 인수인계다.

## 1. 현재 도달 상태

통합 시험에서 다음 흐름까지 확인했다.

```text
MM 자동 주행
→ 베드뷰·토마토 선택
→ APPROACH / PREGRASP / GRASP
→ 파지 검증·절단
→ RETRACT
→ IW FOLLOW·비접촉 도킹
→ BASKET_APPROACH
→ BASKET_PLACE
→ 그리퍼 개방
→ BASKET_RETRACT
→ GO_HOME
```

즉, 수확부터 바스켓 플레이스 릴리즈까지 제어 시퀀스는 연결됐다.

플레이스 시험에서는 토마토가 빈 KLT를 통과했다. 원인은 릴리즈 위치나 토마토
RigidBody가 아니라, 초기 토마토가 들어 있는 KLT에만 collider가 있고 빈 플레이스
대상 `KLT_31`에는 collider가 없었던 것이다.

수정 사항:

- KLT 8개 모두에 `convexDecomposition` collider 적용
- `filled`는 초기 토마토 생성 여부만 결정하도록 분리
- Python 문법 검사, deck geometry 테스트 5개, diff 형식 검사 통과

**아직 수정 후 실제 플레이스 재시험은 하지 않았다.**

## 2. 다음 작업 우선순위

### 1순위 — KLT 물리 수정 재검증

Isaac Sim을 완전히 재시작한 뒤 통합 시험을 다시 실행한다.

확인할 것:

- 플레이스한 토마토가 `KLT_31`을 관통하지 않는가
- KLT 바닥에 정상 안착하는가
- IW가 출발하거나 회전할 때 KLT 밖으로 튀지 않는가
- KLT 8개의 `convexDecomposition` 추가로 physics frame rate가 크게 저하되지 않는가

### 2순위 — 플레이스 위치 미세조정

현재 바스켓 목표는 MM과 가장 가까운 앞쪽 빈 슬롯을 선택하고, release 목표를 MM
쪽으로 `0.06 m` 당긴다.

- 파라미터: `basket_place_toward_mm_m=0.06`
- 슬롯: 현재 초기 적재 기준 `KLT_31`
- release 높이: KLT 윗면보다 `0.05 m`

물리 collider 적용 후 토마토가 벽이나 슬롯 사이에 떨어진다면 시각 관찰을 기준으로
`basket_place_toward_mm_m`을 조정한다.

### 3순위 — 연속 플레이스

현재 빈 슬롯 pose는 실제 점유 상태를 갱신하지 않고 초기 빈 슬롯 후보 중 앞쪽
`KLT_31`을 반복 선택한다.

연속 수확을 구현하려면:

- 플레이스 완료 후 슬롯 점유 상태 갱신
- 다음 빈 슬롯 선택
- 뒤쪽 슬롯까지 사용할 경우 MM 작업영역과 팔 도달성 재검증
- KLT별 토마토 개수 또는 점유 판정 방식 결정

### 4순위 — IW 주행 안전장치

아직 미구현:

- cmd_vel은 존재하지만 odom 이동이 거의 없는 상태를 감지하는 stuck watchdog
- 정지 후 후진·재계획 복구
- 장애물 거리별 강제 감속·정지용 Nav2 Collision Monitor

### 5순위 — 동시 기동 안정성

현재 IW localization은 지연 기동과 lifecycle activator로 보완했다. 하지만 MM
MoveIt, MM Nav2, IW Nav2 동시 기동 시 DDS 응답 유실 가능성이 완전히 제거된 것은
아니다.

후보:

- MM Nav2와 IW navigation에도 동일한 lifecycle 상태 확인·재시도 적용
- FastDDS Discovery Server 도입 검토
- RViz 기동 지연 또는 분리 실행으로 Isaac과 GPU/OpenGL 경합 완화

## 3. 실행 방법

Isaac Sim:

```bash
cd ~/cobot3_ws/isaacpjt
isaac_python main.py --mm --iw --fork --nav --camera
```

ROS2:

```bash
ros2 launch harvest_vision smartfarm_integration.launch.py
```

환경:

```bash
export ROS_DOMAIN_ID=108
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
```

진단 녹화:

```bash
~/cobot3_ws/diagnostics/capture_sim_diag.sh
```

rosbag은 `diagnostics/bags/`에 저장되며 Git 추적 대상이 아니다. 현재는 최신 녹화본
`sim_diag_20260725_124553`만 로컬에 남아 있다.
